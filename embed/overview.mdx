Embed is Photon's prescribing UI. It covers the prescriber's whole workflow: signing in, finding the patient, choosing the drug, reviewing screening, signing and sending. You place it in your app and give it the records you already have.

## Three ways to use it

| | [React components](/embed/react) | [iframe](/embed/iframe) | [App link](/embed/links) |
| --- | --- | --- | --- |
| What it is | `<PhotonOrder />` and friends, rendered in your page | Photon's page inside yours | A URL that opens Photon in a new tab |
| Looks like | Your app: it uses your styles and components | Photon, on a transparent background | Photon |
| Sign-in | Your Application `client_id` | Photon's own (no credentials) | Photon's own (no credentials) |
| Events | Callbacks with live objects | `postMessage` with ids | None |
| Best for | React apps | Other frameworks, or the fastest start | Email, SMS, or a button in a backend tool |

All three show the same cards and follow the same rules, and they're all built on the [JavaScript client](/embed/javascript).

## The cards

| Card | Shows | Use it for |
| --- | --- | --- |
| `PhotonOrder` | The patient, a card for each prescription, then **Send** | Prescribing. Most integrations need only this card. |
| `PhotonPatient` | Find or add a patient, and edit their details | Patient intake on its own |
| `PhotonPrescription` | One prescription: drug, sig, dispense, screening, **Sign** | A single prescription inside your own flow |

## Giving it records

Each card takes its records (`patient`, `prescription`, `order`) the same way. Pass whatever you have:

| You pass | Example | Embed |
| --- | --- | --- |
| An id | `"pat_01M3WQ…"` | Opens that record (get) |
| Fields, no id | `{ demographic: { name, dateOfBirth, sex } }` | Finds, matches or adds it (sync) |
| An id with fields | `{ id: "pat_01M3WQ…", demographic: { phone } }` | Updates only those fields (update) |

These are the same [get, sync and update](/how-photon-works#get-sync-and-update) calls the API uses, with the same field names. An order can also take prescriptions, either drafts by id (`{ id: "rx_…" }`) or new ones from a template (`{ templateId }`).

## Environments

Embed runs at `https://rx.neutron.health` in the sandbox and `https://rx.photon.health` in production. The React components choose one with `environment`. See [Environments](/environments).
