Every event has the [same envelope](/network/webhooks#the-request). This page lists each `type` and its `data`.

| Event | When |
| --- | --- |
| `photon:order:created` | An order was sent |
| `photon:order:placed` | The order reached a pharmacy |
| `photon:order:fulfillment` | The pharmacy made progress: received, ready, shipped and so on |
| `photon:order:rerouted` | The order moved to a different pharmacy |
| `photon:order:completed` | Picked up or delivered |
| `photon:order:canceled` | Canceled |
| `photon:prescription:created` | A prescription was created |
| `photon:prescription:depleted` | All of a prescription's fills have been used |
| `photon:prescription:expired` | A prescription expired |

Most events include the `patient` as `{ id, externalId }` and the record's own `externalId` when one was set.

## Order events

### photon:order:created

An order was sent. Each prescription on it becomes a fill.

```json
"data": {
  "id": "ord_01M3WT5GK51DBRH7ZKBKBV9QWK",
  "externalId": "1234",
  "pharmacyId": "phr_01GA9HPW4SJGXGZSYA8FNCPM8C",
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" },
  "fills": [
    { "id": "fil_01G8AHAFNSH1PJMGWECX3BYEP2", "prescription": { "id": "rx_01M3WT4NERS2YVQRF6YTWR4A6C", "externalId": "1234" } }
  ],
  "createdAt": "2026-10-08T01:00:00.000Z"
}
```

### photon:order:placed

The order was sent to a pharmacy. If the order is rerouted, you get this event again for the new pharmacy.

```json
"data": {
  "id": "ord_01M3WT5GK51DBRH7ZKBKBV9QWK",
  "externalId": "1234",
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" },
  "pharmacy": {
    "id": "phr_01J6APWHGNFJCE74SB031VYABC",
    "name": "Example Pharmacy",
    "address": { "street1": "4343 Test Street", "city": "Georgetown", "state": "KY", "postalCode": "40004" }
  }
}
```

### photon:order:fulfillment

The pharmacy made progress. You get one event for each step.

```json
"data": {
  "id": "ord_01M3WT5GK51DBRH7ZKBKBV9QWK",
  "externalId": "1234",
  "fulfillment": { "type": "MAIL_ORDER", "state": "SHIPPED", "carrier": "USPS", "trackingNumber": "1LS729104296564" },
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" }
}
```

| `fulfillment.type` | `fulfillment.state` |
| --- | --- |
| `PICK_UP` | `SENT` (awaiting the pharmacy's confirmation), `RECEIVED` (the pharmacy confirmed it can fill it), `READY` (waiting for pickup), `PICKED_UP` |
| `MAIL_ORDER` | `SENT`, `FILLING`, `SHIPPED`, `DELIVERED` |

`SHIPPED` and `DELIVERED` include `carrier` and `trackingNumber` when the pharmacy provides them.

### photon:order:rerouted

The order moved to a different pharmacy, usually because the patient chose another one.

```json
"data": {
  "id": "ord_01M3WT5GK51DBRH7ZKBKBV9QWK",
  "externalId": "1234",
  "pharmacy": {
    "id": "phr_hRBVwyp23qjQR0ap",
    "name": "CVS",
    "address": { "street1": "123 Main St", "city": "Brooklyn", "state": "NY", "postalCode": "11111" }
  },
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" }
}
```

### photon:order:completed

Picked up or delivered.

```json
"data": {
  "id": "ord_01M3WT5GK51DBRH7ZKBKBV9QWK",
  "externalId": "1234",
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" }
}
```

### photon:order:canceled

Canceled. Its `data` has the same shape as `photon:order:completed`.

## Prescription events

### photon:prescription:created

```json
"data": {
  "id": "rx_01M3WT4NERS2YVQRF6YTWR4A6C",
  "externalId": "1234",
  "medicationId": "med_01G7T2NB6",
  "prescriberId": "usr_wUofzqEvcA2JCwJ4",
  "instructions": "Take once daily",
  "notes": "",
  "dispenseQuantity": 30,
  "dispenseUnit": "EA",
  "dispenseAsWritten": true,
  "refillsAllowed": 12,
  "daysSupply": 30,
  "effectiveDate": "2026-10-08",
  "expirationDate": "2027-10-08",
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" }
}
```

| Field | Description |
| --- | --- |
| `medicationId` | The drug's catalog id (`med_…`) |
| `prescriberId` | The prescriber who signed it |
| `effectiveDate`, `expirationDate` | When the prescription is valid |

### photon:prescription:depleted

Every fill has been used. This is normal at the end of a prescription, not an error.

```json
"data": {
  "id": "rx_01M3WT4NERS2YVQRF6YTWR4A6C",
  "externalId": "1234",
  "patient": { "id": "pat_01M3WQQHRB1T0K1469KD18BAWX", "externalId": "1234" }
}
```

### photon:prescription:expired

The prescription passed its `expirationDate`. Its `data` has the same shape as `photon:prescription:depleted`.
