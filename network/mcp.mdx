Add Photon to your chat and connect your account, then ask the assistant to send a prescription. It uses Photon's tools to match the patient, sync relevant clinical context from the conversation and prepare the order using the treatment details you've discussed. The assistant asks for anything missing and shows you the prescriptions and screening results to review before you approve sending.

## From a request to a prescription

You don't need a special prompt or every detail up front. Start with a request like:

> Send a prescription for amlodipine to Paige Turner.

1. **Describe what you need.** Photon looks for the patient and medication using the details you've shared. The assistant asks for anything missing, such as the patient's date of birth or the prescription directions.
2. **Review the prescription.** Check the patient, medication, directions, quantity and any screening findings. You can ask for changes before approving. If the order contains more than one prescription, review them together.
3. **Approve sending.** Once you're happy with the complete order, tell the assistant to send it. Signing and sending require an authorized prescriber; if verification is needed, Photon guides you through it. You can also continue in [Prescribe](/prescribe/overview).
4. **Check what happens next.** Ask about the order's status or available pharmacies. A submitted order has been accepted by Photon; the status tells you when it reaches the pharmacy and progresses toward fulfillment.

You don't need to choose a pharmacy before sending. Photon lets the patient choose where to fill. If you want a specific destination for an order, include it in your request.

## Tools

The assistant uses these tools behind the conversation. You can also call them from your own agent.

| Tool | What you can do |
| --- | --- |
| [`patient`](/network/mcp/prescribing#patient) | Find or add a patient and update their details and clinical history. |
| [`prescription`](/network/mcp/prescribing#prescription) | Find a medication, prepare or edit a prescription, and sign it when needed. |
| [`order`](/network/mcp/prescribing#order) | Put prescriptions into an order, send it after approval, or change its pharmacy. |
| [`orders`](/network/mcp/fulfillment#orders) | Check order status and compare available pharmacies and prices. |
| [`organizations`](/network/mcp/admin#organizations) | See your organizations and invitations, or switch where you're working. |

See [Prescribing](/network/mcp/prescribing) for patient, prescription and order examples, or [Fulfillment](/network/mcp/fulfillment) for status and pharmacy options.

## Connect your own agent

Use an MCP client with Streamable HTTP support. Test with a Neutron account before working with real patients in Photon.

[Connect a client](/network/mcp/connect) covers server addresses, sign-in and approval for your own OAuth client. See [Admin](/network/mcp/admin) to manage organizations. A backend agent can use [API credentials](/authentication#machine-tokens) to prepare drafts, then [hand them to a prescriber](/integrations/agent-drafted-orders) to review and send. Machine tokens cannot sign prescriptions.
