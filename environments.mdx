Photon has two environments. They run the same API but keep separate data, accounts and credentials.

| | **Neutron** (sandbox) | **Photon** (production) |
| --- | --- | --- |
| Use it for | Building and testing | Real patients and real prescriptions |
| Prescriptions | Never sent to a real pharmacy | Sent to pharmacies |
| Patients | Fake ones only | Real |
| Credentials | Free with every sandbox account | A paid feature |
| Prescribe app | [rx.neutron.health](https://rx.neutron.health) ⚠️ | [rx.new](https://rx.new) |
| [Dashboard](/dashboard) | [app.neutron.health/settings](https://app.neutron.health/settings) | [app.photon.health/settings](https://app.photon.health/settings) |

<Tip>
  Build everything against Neutron. Every link and example in these docs points there unless it says otherwise.
</Tip>

## URLs

Every URL follows from the environment's name, so switching environments means changing one word. The one exception is the Prescribe app, which is `rx.new` in production.

| Service | Neutron | Photon |
| --- | --- | --- |
| GraphQL | `https://network.neutron.health/graphql` | `https://network.photon.health/graphql` ⚠️ |
| MCP ([private preview](/network/mcp)) | `https://network.neutron.health/mcp` ⚠️ | `https://network.photon.health/mcp` ⚠️ |
| Prescribe app | `https://rx.neutron.health` ⚠️ | `https://rx.new` |
| Sign-in (Auth0) | `auth.neutron.health` | `auth.photon.health` |
| Token audience | `https://api.neutron.health` | `https://api.photon.health` |

## In code

Prescribe and the JavaScript client take the environment's name:

<CodeGroup>

```tsx React
<PhotonProvider clientId="YOUR_CLIENT_ID" environment="neutron">
```

```ts JavaScript
const ph = photon({ environment: "neutron", auth: { clientId: "YOUR_CLIENT_ID" } });
```

</CodeGroup>

<Warning>
  `PhotonProvider` defaults to production (`photon`). Set `environment="neutron"` while you build.
</Warning>

For GraphQL or MCP, use the URLs above.

## Going live

1. [Request a production account](https://photonhealth.com/onboard#clinic), or email [sales@photon.health](mailto:sales@photon.health) to talk through your use case.
1. Get production credentials from [app.photon.health](https://app.photon.health/settings/developers). Sandbox credentials don't work in production.
2. Change the environment from `neutron` to `photon`: the `environment` prop, or the hostnames for GraphQL and MCP.
3. Add your production domain to your Application credential's allowed URLs.
5. Set up your [webhooks](/network/webhooks) in production too.
