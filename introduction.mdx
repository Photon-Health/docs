---
title: "Photon Prescribe API"
sidebarTitle: "Introduction"
description: "Photon Prescribe API is a GraphQL API that covers the full prescription lifecycle - from patient intake through pharmacy order submission."
---

This API powers every stage of the prescription workflow: from capturing patient demographics and clinical history, through drafting and signing prescriptions, to routing orders to the right pharmacy and surfacing real-time offers. Whether you are building a telehealth platform, an EHR integration, or an AI-assisted prescribing tool, the API gives you a single, typed interface to the complete prescription lifecycle.

This API is uniquely different as all the actions are done within the context of routing in the pharmacy network. It was created this way to encourage builders to be hyper-focused on exactly the actions they intend to execute. There are no queries. The only Query is ping used for a health check. Instead, only three mutations are outlined: patient, prescription, and order. These mutations are all similarly structured, have detailed responses, and are purposefully built to guide users to their intended action.
