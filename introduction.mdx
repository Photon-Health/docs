This API powers every stage of the prescription workflow: **patient** intake, **prescriptions** drafting, **coverage** checks, **interaction** screening, and **order** routing.

Whether you are building a telehealth platform, an EHR integration, or an AI-assisted prescribing tool, the API gives you a single, typed interface to the complete prescription lifecycle.
