Photon lets your product prescribe. A prescriber finds the patient, writes the prescription, signs it and sends it. The patient then picks a pharmacy and gets their medication.

Photon comes as two products: 

<CardGroup cols={2}>
  <Card title="Embed" icon="window" href="/embed/overview">
    The prescribing UI: React components, an iframe or a link. It handles sign-in, drug search, screening, signing and sending.
  </Card>

  <Card title="Network" icon="diagram-project" href="/network/overview">
    The API underneath. Use GraphQL from your backend or MCP from an agent to keep patients in sync and draft prescriptions and orders.
  </Card>
</CardGroup>

Most integrations use both: Embed for the prescriber, and Network from your backend to fill in what you already know.

## Start here

<Steps>
  <Step title="Get a sandbox">
    [Request a Neutron sandbox](https://photonhealth.com/onboard#developer), then find your credentials in the [dashboard](https://app.neutron.health/settings/developers). See [Environments](/environments).
  </Step>
  <Step title="Learn the model">
    Photon has three records: patients, prescriptions and orders. [Architecture](/architecture) covers them in a few minutes.
  </Step>
  <Step title="Add the prescribe embed">
    Most teams start with one component on their patient page. See [Prescribe embed](/integrations/prescribe-embed).
  </Step>
</Steps>

```tsx
import { PhotonOrder, PhotonProvider } from "@photon-rx/react";

<PhotonProvider clientId="YOUR_CLIENT_ID" environment="neutron">
  <PhotonOrder
    patient={{
      demographic: {
        name: { first: "Paige", last: "Turner" },
        dateOfBirth: "1990-01-01",
        sex: "FEMALE",
        phone: "+13175550142",
      },
    }}
  />
</PhotonProvider>
```
