In a few minutes you'll render Photon's order card in your app, prescribe for a test patient, and send it. Everything here runs in **Neutron**, the sandbox, where nothing reaches a real pharmacy.

<Steps>
  <Step title="Get a sandbox">
    [Sign up for Neutron](https://photonhealth.com/onboard#developer). Your account is ready right away.

    In the [dashboard](https://app.neutron.health/settings/developers), open **Settings → Developers**. Copy your **Application** `client_id`, and add your app's URL (for example, `http://localhost:5173`) to its allowed URLs.
  </Step>
  <Step title="Install">
    ```bash
    npm install @photon-rx/react
    ```

    {/* TODO(launch): publish to npm, then delete this line. */}
    ⚠️ Not published to npm yet.
  </Step>
  <Step title="Render the order card">
    Pass a test patient. Photon finds them or adds them.

    ```tsx Prescribe.tsx
    import { PhotonOrder, PhotonProvider } from "@photon-rx/react";
    import "@photon-rx/react/styles.css";

    export function Prescribe() {
      return (
        <PhotonProvider clientId="YOUR_CLIENT_ID" environment="neutron">
          <PhotonOrder
            patient={{
              demographic: {
                name: { first: "Paige", last: "Turner" },
                dateOfBirth: "1990-01-01",
                sex: "FEMALE",
                phone: "+13175550142",
              },
            }}
            onSent={(order) => console.log("Sent", order.id)}
          />
        </PhotonProvider>
      );
    }
    ```
  </Step>
  <Step title="Prescribe">
    1. Click **Sign in to Photon** and sign in with your Neutron account.
    2. Search for a drug, such as `amlodipine`, and fill in the sig and quantity. Screening runs as you go.
    3. Click **Sign**, then **Send**.

    In production, the patient would now get a text with their pharmacy options and prices. In Neutron, the order is created but never sent to a real pharmacy.
  </Step>
  <Step title="Check it worked">
    Your console logs `Sent ord_…`. That id is the order you just sent: its `state` is now `SUBMITTED`. Open it in the Prescribe app at `https://rx.neutron.health/order/ord_…`, or read it with the [`order` mutation](/network/order).
  </Step>
</Steps>

## What you just did

| You | Photon |
| --- | --- |
| Passed a patient | Found or added the patient record (`pat_…`) |
| Searched for a drug and filled in the sig | Created a draft prescription (`rx_…`) on a draft order (`ord_…`), and screened it |
| Clicked **Sign** | Recorded the prescriber's approval. The prescription can't change now. |
| Clicked **Send** | Submitted the order. **This is the send.** In production, Photon texts the patient and transmits to a pharmacy once they choose one. |

See [From draft to pharmacy](/architecture#from-draft-to-pharmacy) for every step after the send.

<Tip>
  Not using React? The [iframe](/prescribe/embed/iframe) does the same with a URL and needs no credentials. Want to try Photon without code? [Connect Claude](/network/mcp/connect) to the sandbox and ask it to prescribe.
</Tip>

Building from your backend instead? The smallest backend path is four calls and a link: get a machine token, sync the patient, draft a prescription from a template, draft the order, then send the prescriber a [deep link](/prescribe/app/deep-links) to sign and send it. Follow [One-click orders](/integrations/one-click-orders).
