## Changes

See [Errors](/reference/errors) for how to handle changes.

### `ChangeStatus`

Used in `Change.status`.

| Value | Meaning |
| --- | --- |
| `APPLIED` | Accepted. Not saved if another change in the request is `BLOCKING`. |
| `REJECTED` | Not saved. Failed validation, a conflict, or a safety rule. |
| `AMBIGUOUS` | Not saved. Several candidates matched; pick one from `options` and retry. |

### `ChangeSeverity`

Used in `Change.severity`.

| Value | Meaning |
| --- | --- |
| `INFO` | No action needed. |
| `ADVISORY` | Worth showing the user. Does not block. |
| `BLOCKING` | Must be resolved. Currently, nothing in the request is saved until it is. |

### `ChangeOperation`

Used in `Change.operation`. Describes the input's operation, not a before/after comparison.

| Value | Meaning |
| --- | --- |
| `ADDED` | The input adds something. Lookups search the global catalog. |
| `MODIFIED` | The input updates something already on the record. |
| `REMOVED` | The input removes something. Lookups search only the record's current list. |

### `ChangeCategory`

Used in `Change.category` (can be `null`) and `ScreeningAlert.category` (always set). Independent of status and severity.

| Value | Meaning |
| --- | --- |
| `DISAMBIGUATION` | Several things match the reference. Pick one. |
| `OBSOLETE_REFERENCE` | The code or product is retired or discontinued. |
| `CODING_SPECIFICITY` | The code is valid, but a more specific one is preferred for claims. |
| `COST_SAVINGS` | A cheaper equivalent exists. |
| `PRODUCT_PREFERENCE` | A specific brand or manufacturer may matter, for example narrow-therapeutic-index drugs, patient recognition, or a payer or dispense-as-written requirement. |
| `SAFETY` | A clinical risk: interaction, allergy conflict, or cross-reactivity. |
| `MISSING_INPUT` | Data needed to proceed is absent. |
| `INVALID_INPUT` | The value is invalid or not supported. |
| `CONFIRMATION_REQUIRED` | The action would succeed but needs explicit confirmation. |

## Prescriptions

### `DraftStatus`

Used in `Prescription.status`. Set by screening alerts.

| Value | Meaning |
| --- | --- |
| `READY` | No warning or blocking alerts. |
| `WARNING` | Has alerts to review. None block sending. |
| `BLOCKED` | Has an alert that prevents sending. |

<Warning>
  The API cannot acknowledge or override alerts. A `BLOCKED` draft stays `BLOCKED`.
</Warning>

### `ScreeningSeverity`

Used in `ScreeningAlert.severity`.

| Value | Meaning |
| --- | --- |
| `MINOR` | Low concern. Never blocks. |
| `MODERATE` | Notable concern. Blocks the draft. |
| `MAJOR` | Serious concern. Blocks the draft. |

### `ScreeningAlertType`

Used in `ScreeningAlert.type`. Says what conflicted; `category` says why it matters.

| Value | Meaning |
| --- | --- |
| `DRUG` | Drug-drug interaction. |
| `ALLERGEN` | Conflicts with an allergy on the patient's record. |
| `CONDITION` | Conflicts with a diagnosis on the patient's record. |

### `PrescriptionSigningState`

Used in `Prescription.signing.state`. To sign, send the returned `contentHash` as `signing.signedHash`.

| Value | Meaning |
| --- | --- |
| `UNSIGNED` | No valid signature. |
| `SIGNED` | The signature matches the current `contentHash`. |
| `INVALIDATED_SIGN` | The signature does not match: the draft changed after signing, or the wrong hash was sent. Sign again with the new `contentHash`. |

## Orders and pharmacies

### `OrderState`

Used in `OrderInput.state`. Defaults to `DRAFT`.

| Value | Meaning |
| --- | --- |
| `DRAFT` | Editable. Nothing is sent. |
| `SUBMITTED` | Sent for fulfillment. After this, you can only change the pharmacy or cancel. |
| `CANCELED` | Canceled. Only allowed from `SUBMITTED`. |

### `OrderExceptionType`

Used in `Order.exceptions[].type`. A problem with the order that needs attention. Always empty for a `DRAFT` order.

| Value | Meaning |
| --- | --- |
| `ORDER_ERROR` | General order error. |
| `DEMOGRAPHIC_MISMATCH` | Patient demographics do not match. |
| `PHARMACY_UNREACHABLE` | The pharmacy cannot be reached. |
| `PHARMACY_CLOSED` | The pharmacy is closed. |
| `EXTERNAL_TRANSFER` | The order was transferred externally. |
| `PHARMACY_DOES_NOT_ACCEPT_INSURANCE` | The pharmacy does not accept the patient's insurance. |
| `PHARMACY_NEEDS_INSURANCE_INFO` | The pharmacy needs insurance information. |
| `SUPERVISING_PHYSICIAN_NEEDED` | A supervising physician is required. |
| `DOCTOR_NOT_LICENSED_IN_STATE` | The prescriber is not licensed in the patient's state. |

### `FulfillmentType`

Used in `PharmacyReferenceInput.fulfillmentType` (filter) and `Pharmacy.fulfillmentType`.

| Value | Meaning |
| --- | --- |
| `MAIL_ORDER` | Delivered by mail. |
| `PICK_UP` | Picked up at the pharmacy. |

### `OfferPriceType`

Used in `PharmacyOffer.priceSummary.priceType`.

| Value | Meaning |
| --- | --- |
| `CASH` | Cash price. |
| `INSURANCE` | Insurance price. |
| `MEMBERSHIP` | Membership price. |

## Patients

### `Sex`

Used in `demographic.sex`. Used for matching and clinical purposes. Gender is a separate free-text field.

| Value | Meaning |
| --- | --- |
| `MALE` | Male. |
| `FEMALE` | Female. |
| `UNKNOWN` | Not provided or not known. |

### `MedicationHistoryStatus`

Used in `clinical.medications[].status`.

| Value | Meaning |
| --- | --- |
| `ACTIVE` | Currently taking it. |
| `HISTORICAL` | Took it in the past, not now. |
| `UNKNOWN` | Not known. |

| `EMBEDDABLE_COMPONENT` | Embedded component. |
| `DIRECT_API` | Direct API integration. |
| `MCP_CONNECTOR` | MCP connector. |
| `LLM_AGENT` | LLM agent. |
